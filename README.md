# StuDash updates

This repository publishes the announcements displayed in the StuDash extension.

Edit announcements.json and commit to main. Each item needs a unique id, an ISO date (YYYY-MM-DD), a title, and a plain-text body. The newest six entries appear in StuDash. The extension checks every 30 minutes, and its refresh button checks immediately.

Set announcements to an empty array to clear the list.
